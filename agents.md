## Check before writing code
Before implementing anything, check installed packages/dependencies first. Do not reimplement functionality that an existing package already provides. If unsure whether a package covers something, ask instead of guessing or writing it from scratch.

## Scope discipline
Only do what was explicitly requested. Do not add extra features, refactors, cleanup, or "improvements" that weren't asked for. If something seems needed to complete the task but wasn't explicitly requested, stop and ask first — explain why it's needed before implementing it.

## Plan before acting
Before making any change, explain the plan: what you're going to do and how eg implementation details. Wait for that to be understood/approved before touching code.

## Approvals
Don't bundle everything into one giant approval request. Split changes into separate, reviewable chunks and ask for approval on each one individually rather than dumping the whole plan at once.
